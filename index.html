How Prism works

Your models

Add any OpenAI-compatible endpoint in models.json — proxy URL, API key, model ID, and an icon (URL, emoji or initials). They appear under Your models.

Free models

The Free · no key tab auto-fetches live models that need no account or API key, from several keyless providers. Free tiers are rate-limited — if a request is throttled, wait ~30s or add your own model.

Auto mode

With Auto on, several models work in sequence: one plans, another drafts, a third polishes and connects everything into the final answer. Any stage that fails is skipped gracefully.

Agent abilities

Capable models can fetch web pages, search, read GitHub repos and run JavaScript in a sandbox. If a model can't use a tool, it simply continues without it.
